# Gemini CLI instructions

For Neovim changes, read and follow [`AGENTS.md`](AGENTS.md). It is the shared source of truth for Codex and Gemini CLI, including Colemak-DH mappings, Blink/LuaSnip/Roslyn completion, snippet conventions, persistence behavior and verification requirements.

Inspect the existing configuration first, preserve unrelated edits, run focused checks, and update [`CHANGELOG.md`](CHANGELOG.md) for meaningful changes.
